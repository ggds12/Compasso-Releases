# Compasso para Windows

Aplicativo de organização financeira pessoal. Os registros e backups ficam no seu computador.

## Instalar

1. Abra a [versão mais recente](https://github.com/ggds12/Compasso-Releases/releases/latest).
2. Em **Assets**, baixe o arquivo **Compasso-Setup-…-x64.exe**.
3. Execute o instalador e abra **Compasso** pelo menu Iniciar.

Se você já usava o Compasso no navegador, abra **Ajustes → Backup completo → Exportar** no navegador e restaure o arquivo em **Ajustes → Restaurar backup** no aplicativo.

## Atualizar

Quando houver uma nova versão, clique em **Chegou atualização**, acima do perfil. Depois que o download terminar, clique em **Reiniciar e atualizar**.
